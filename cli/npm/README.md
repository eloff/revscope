# revscope

The [RevScope](https://revscope.co) command line client: sign up, install the tracker on a site, connect integrations, and query analytics.

```sh
npx revscope --help
```

This package fetches the native binary for your platform the first time it runs, and checks it against the release's checksum. See the [CLI docs](https://revscope.co/docs/cli).
