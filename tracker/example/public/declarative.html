data-revscope-click / visible / beacon / metadata

Declarative HTML events

Mark elements with data-revscope-click, data-revscope-beacon, data-revscope-visible, or data-revscope-metadata. Event attributes take an event name plus optional space-separated key=value pairs. Named <a> tags without href also fire a-{id|name} when scrolled into view.

Page metadata

data-revscope-metadata is key=value pairs only (no event name). Scanned on each pageview like the JS metadata command — only changed keys are sent.
