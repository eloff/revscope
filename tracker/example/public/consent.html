Consent and tracking choices

Cookies: rcexample (1/0/2) and rsexample (session id when persistence is allowed). Granting consent lets the server persist the session; revoking clears the landing cookie and uses cookieless measurement; disabling stops all measurement. Subsequent pageviews/events include c=true|false when tracking is enabled and consent is known. Call dispatch("consent_status", callback) to learn whether this visitor's region requires a consent prompt ("granted" | "denied" | "disabled" | "required" | "not_required").
