revscope-outbound-click

Outbound & mailto tracking

Clicks on links that leave this hostname (or mailto:) fire revscope-outbound-click with meta.to set to the destination hostname (or mailto:domain). Delivered via sendBeacon so it lands before navigation. Middle-click / auxclick is covered too.
